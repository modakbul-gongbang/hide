# hide brand and third-party marks

## hide

The product display name is `hide` and the bundle identifier is `me.grab.hide`.
The application uses the text wordmark and system icons until a user-selected ima2 app icon is approved.
No icon candidate is treated as selected by the build.

## claude and codex

The agent picker uses the original single-letter glyphs `C` and `O` rather than bundling third-party logos.
They identify the executable kind without implying endorsement or reproducing a protected mark.
