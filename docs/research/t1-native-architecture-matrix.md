# T1 Native Architecture Research Matrix

Research date: 2026-08-27.

This document compares product references and implementation candidates for the T1 architecture preflight.

It uses release pages, tagged source, current official repository state, Apple documentation, crates.io metadata, and project documentation as primary evidence.

GitHub stars are not an input to any decision.

An accepted candidate is still provisional until the release `.app` spike fills the evidence slots in [ADR-0001](../architecture/adr-0001-native-surface-ownership.md).

`NOT_PROVEN` means that upstream documentation or a source review cannot prove behavior in the integrated Herdr IDE release build.

## Evaluation policy

- A dependency must have a clear license, an exact version or commit, recent maintainer activity or a defensible platform-owned update path, and a bounded responsibility.
- A product reference may inform interaction or ownership, but its runtime, benchmark, source code, and assets do not become Herdr IDE evidence.
- macOS arm64 and x86_64 support is recorded separately from universal application packaging because source portability does not prove a valid release bundle.
- IME and Accessibility ownership is recorded even when a candidate has no responsibility for either surface.
- Security updates use an exact lockfile, upstream release and advisory monitoring, and a new compatibility spike whenever a native ABI, browser revision, cryptographic stack, or 0.x API changes.
- No upstream benchmark proves the PRD limits for warm launch, terminal presentation, idle CPU, or full process-tree RSS.

## Research conclusions

- The approved ownership model remains coherent on paper because AppKit can own native views, wgpu can render Metal-backed IDE surfaces, and cef-rs exposes a macOS native child Browser path.
- The model is not proven in combination because no official source demonstrates this application's focus, z-order, Retina, Korean IME, AX, pane zoom, helper bundle, or process-tree behavior.
- The current `alacritty_terminal 0.26.0` release must not be frozen without the later zero-width-character memory bound, so the provisional pin is the exact upstream fix commit until a containing release is verified.
- The official.browser runtime is deprecated, its successor uses a rejected Electron and frame-copy architecture, and only its ownership concepts remain usable.
- Herdr Pet's pinned standalone source exposes sizes `124`, `152`, and `176` with default `152`, but the IDE-owned Pet remains fixed at the sealed contract's `124x124` while drag, state, asset, clamp, persistence, and click behavior remain the parity references.
- All five hard performance budgets remain `NOT_PROVEN` until a fixed release build, target machine, sample count, process tree, and fixture are recorded.
