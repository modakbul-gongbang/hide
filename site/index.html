Measured performance

The numbers,
with their conditions.

A private native candidate on an M4 Pro Mac, measured October 4, 2026. Read the method and limits alongside the results.

16.3 ms p95 for idle input processing
First renderer keydown to a complete nine-character echo in the terminal buffer, across 50 samples.
99.5 ms p95 for scroll processing
Wheel event to changed terminal text and the next animation frame after synthetic output, across 50 samples.
549.0 MiB idle, 622.0 MiB under load
p95 RSS summed across the desktop, daemon and private Herdr process trees, from 20 samples in each condition. The load drove three terminal panes.
Measured boundaries
An unpackaged desktop host with a release daemon. Input timings do not measure physical pixel presentation, and no matched Orca comparison completed.
