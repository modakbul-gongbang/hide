Why an ADE

Editors were built for one author. Your work now has many.

An agent development environment starts from the agents: where each one runs, what it is doing, and which one is waiting on you. Four ideas carry it.

01 / Multi-agent

Every agent.
The same experience.

Each agent keeps its own CLI, login and habits. hide reads them all the same way: one status, one generated title, one place to answer, one way to start, delegate and put to sleep.

  • Four groups on every surface: Needs you, Done, Working, Seen.
  • Agents delegate to each other, and the lineage stays in view.
  • A sleeping agent wakes with its conversation.
AgentsThis Mac

02 / Multi-device

Every machine.
The same experience.

Add the desktop upstairs or a rented server by its SSH alias. Its agents join the same groups, its panes open files and diffs in the hide in front of you, and your phone answers the one that needs you.

  • Start an agent on any connected device from your Mac.
  • Needs you and Done badges for every device, in one rail.
  • Your phone pairs by QR, over your own Tailscale and only inside it.

03 / Hide AI

Less to hold
in your head.

Hide AI reads what your agents did and gives each one a short title and summary, names new worktrees, and keeps a Project Memory your agents can recall. It runs on the agent CLI you already signed in to, so there is no key to add.

  • A title and summary for every agent, so you don't read every terminal.
  • Project Memory is opt-in per project and stays on your Mac.
  • Choose which agent runs it, and a fallback order.

Hand the Factory tasks whose requirements are clear. Worker agents take them in dependency order, verify and merge them, and bring back only what needs a person.

  • Code runs the rules: order, slots, checks and merges.
  • Factory AI answers only the questions your mode hands it.
  • Permissions always reach you: cost, sign-in, deletion, anything irreversible.
